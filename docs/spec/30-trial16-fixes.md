# 30. 16 回目の試行で見つかった問題の修正（M22）

## 背景

16 回目の試行（[29-trial15-fixes.md](29-trial15-fixes.md)）で、AI は緑サイエンスの目標を達成した。そのうえで次の問題を挙げた。

| 区分 | 問題 | 原因 |
| --- | --- | --- |
| AY | 経路があるのに、歩く途中で建物に当たって止まった（`blocked`）。同じ組立機の角で 2 回止まった | 経路探索はキャラクターの幅で通れる経路を返す。歩く処理は、次の点への向きを 8 方向に丸めて歩くので、斜めの区間で経路からずれ、角に当たる |
| AZ | 目的地が深い水や炉の上のとき、`move_to` が `path_not_found` になった | 目的地に立てないときも、目的地そのものへの経路を探す。立てる近くの位置（`nearby_free_position`）は返すが、そこへは歩かない |
| BA | 燃料式掘削機を置こうとすると、資源が無いと言われた。隣の位置では置けた | 採掘範囲の資源は、置けなかったときにしか返さない。置く前に、どの位置なら資源に掛かるかが分からない |
| BB | 電柱の届く範囲の小さなすき間で、機械が電気につながらず止まった | 置いた結果に、電気のネットワークにつながったかを返していない |
| — | 移動に失敗したあとに続けて呼んだ受け渡しが、届かずにまとめて失敗した | 別々の呼び出しのつながりなので、ツールでは扱わない。説明で、移動の結果を確かめてから続けるよう案内する |

## AY. 経路に沿って歩く

- 歩く向きを、次の点への向きを丸めるだけで決めない。今の区間（前の点から次の点まで）の線から、キャラクターが離れすぎないように、隣り合う 2 つの向きのうち、線に近づく方を選ぶ。
- 引っかかって探し直すときも、同じ選び方で歩く。歩くのはゲームの通常の移動で行う。

## AZ. 立てない目的地

- 目的地にキャラクターが立てない（地形や設備がふさいでいる）とき、目的地から 10 タイル以内の立てる位置を目的地にして歩く。結果に、もとの目的地と、実際に向かった位置 `goal_adjusted` を返す。
- `within` を指定したときは、従来どおり、もとの目的地の近くまで歩く。

## BA. 掘削機の採掘範囲の予告

- 採掘機（`mining-drill`）の `check_placement` で、置けるときも、採掘範囲の資源の種類ごとのタイル数 `mining_area_resources` を返す。置いた結果にも返す。

## BB. 置いた機械の電気のつながり

- 電気で動く設備と電柱を置いた結果に、電気のネットワークにつながったか（`electric_network_connected`）と、そのネットワークの番号を返す。つながらないときは、ヒントで、電柱の届く範囲を `check_placement` の `electric_coverage` で確かめるよう案内する。
