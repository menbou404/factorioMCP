# 05. 採掘と持ち物

## 操作

`mine_entity(target, count)` は近くの資源または通常の手掘り対象を採掘する。`target` は直前の周囲観察で得た対象識別子と位置、`count` は正の整数とする。初期版は鉱石、石、石炭、木のような手掘り可能な対象を扱う。

## 実行規則

1. キャラクターが生存し、対象が同じ面にあり、まだ存在し、採掘可能であることを確認する。
2. 採掘距離、必要な道具、持ち物の空き容量をゲームの状態に照らして確認する。`force` による強制採掘は使わない。
3. キャラクターを対象に向け、ゲームの採掘状態を開始する。対象ごとの通常の採掘時間を経過させる。時間を飛ばす即時採掘を AI に提供しない。
4. 成功後はキャラクターの実インベントリを読み、増分と対象の変化を返す。AI にアイテムを直接支給しない。
5. 対象消失、距離超過、容量不足、死亡、キャンセルで停止する。

独立キャラクターで標準の採掘状態が実際の資源取得まで行うかを実機で検証する。標準状態がアニメーションのみの場合は、通常の採掘時間と距離を満たした後に Factorio の採掘 API を呼ぶ方式を検証する。いずれの場合もアイテム数を任意に増やす処理は認めない。

## アイテム保存則

採掘前後の対象とインベントリを記録する。採掘結果がゲーム上の対象に対応しない場合は成功扱いにしない。アイテム容量を超えた獲得、同一対象からの二重取得、キャンセル後の獲得を禁止する。

## 受け入れ条件

- 対象から離れていると採掘できない。
- 通常の採掘時間より早く資源を得られない。
- 成功時に増えるのは AI キャラクターのゲーム内持ち物であり、人間の持ち物ではない。
- 容量不足や対象消失時に資源が複製されない。

参照: [採掘状態、採掘 API、主インベントリ](https://lua-api.factorio.com/latest/classes/LuaControl.html)。
