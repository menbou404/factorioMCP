# 07. 建設

## 操作

`place_entity(item, surface, x, y, direction)` は AI キャラクターが持つ建設用アイテムを 1 個使い、指定位置に対応する設備を 1 個設置する。初期版は基本ゲームの単純な設備を許可リストに載せる。複数タイル、線路、地下接続、流体設定、青写真による一括建設は段階的に追加する。

## 実行規則

1. キャラクターが生存し、同じ面の位置が作業距離内にあり、対象位置を観察できることを確認する。
2. アイテムが AI キャラクターの実インベントリに 1 個以上あり、アイテムと設備の対応がゲームの定義に一致することを確認する。
3. ゲームの設置可否 API で衝突、地形、向き、勢力などを検証する。通常プレイヤーが建てられない状態で Mod が配置しない。
4. 同じゲーム tick の処理内で、アイテムを 1 個消費し、設備を 1 個生成する。生成失敗時は消費を戻し、成功にしない。二重要求は操作 ID で排除する。
5. 設備の実在とインベントリの減少を確認して成功を返す。必要なゲームイベントを発火させ、他 Mod との整合を検証する。

Factorio のスクリプトによる設備生成は、通常のプレイヤー建設を自動的に再現するとは限らない。上記の検証と材料消費を Mod が責任を持って行う。ゲーム側の追加条件を再現できない設備は許可リストに加えない。

## 受け入れ条件

- 材料なし、距離超過、衝突、未観察位置では建設できない。
- 成功時は設備が 1 個増え、対応するアイテムが AI キャラクターの持ち物から 1 個減る。
- 失敗、再試行、通信切断でアイテムや設備が増減しない、または二重設置されない。
- ベルト等の向きを指定した設備は指定方向で稼働する。

参照: [設置可否と設備生成](https://lua-api.factorio.com/latest/classes/LuaSurface.html)、[キャラクターの建設距離](https://lua-api.factorio.com/latest/classes/LuaControl.html)、[インベントリからの削除](https://lua-api.factorio.com/latest/classes/LuaInventory.html)。
