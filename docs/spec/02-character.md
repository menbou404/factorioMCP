# 02. AI キャラクター

## 責務

Mod は 1 体の独立した `character` エンティティを所有する。AI の位置、体力、持ち物、製作キューはゲーム内のキャラクターを正本とする。MCP サーバーはそれらの写しを永続化しない。

## 生成

- 初回のみ、利用者の開始地点付近から衝突しない位置を探して生成する。位置が見つからなければ失敗を返し、他の物体を消して場所を作らない。
- 人間プレイヤーと同じ勢力に所属させる。初期持ち物を空にし、Mod がアイテムや技術を与えない。
- Mod の保存領域に `agent_id` とキャラクター参照を保存する。初期 `agent_id` は固定の `agent-1`。今後の複数化で ID を増やせる構造にする。
- 同じセーブで再接続しても既存の生存キャラクターを再利用する。

## 状態

`absent`、`alive`、`dead` を区別する。`alive` では現在位置、面、体力、持ち物量、進行中の操作 ID を取得できる。死亡したら歩行・採掘・建設を停止し、操作を失敗で終了する。再生成は AI ツールから自動実行しない。初期版では管理者による明示的な再開操作を設け、その挙動と通常ゲームの死亡時ルールとの整合を実機で確かめる。

## 所有権

人間のキャラクターや他 Mod のキャラクターを操作しない。保存した参照が無効になった場合、外見だけで別のキャラクターを推測して引き継がない。管理者に復旧が必要な状態を返す。

## 受け入れ条件

- 起動、MCP サーバーの再起動、セーブの再読み込みでキャラクターが重複しない。
- AI の持ち物を照会すると、このキャラクターのゲーム内インベントリと一致する。
- 人間プレイヤーが操作中のキャラクターには作用しない。

参照: [エンティティ生成](https://lua-api.factorio.com/latest/classes/LuaSurface.html)、[キャラクターの主インベントリ](https://lua-api.factorio.com/latest/classes/LuaControl.html)、[Mod の保存領域](https://lua-api.factorio.com/latest/index-runtime.html)。
