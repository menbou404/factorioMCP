# 04. 歩行と経路探索

## 操作

`move_to(surface, x, y)` は目的地への歩行を開始し、操作 ID を返す。AI は `get_action_status` で進捗を確認し、`cancel_action` で中止できる。座標はタイル単位の有限数とし、現在の面にある、観察または探索で到達可能な場所に限る。

## 実行規則

- キャラクターの歩行状態を操作して進む。移動中に座標を直接代入したり、テレポートしたりしない。
- Factorio の経路探索を使い、曲がり角や障害物を考慮する。経路探索は非同期なので、結果が出るまで操作は `running` とする。
- 経路外へ進んだ、障害物が新設された、一定時間位置が変わらない場合は再探索する。再探索回数には上限を設ける。
- 目的地への到着は、キャラクターの実際の位置が許容距離内に入ったことをもって判定する。許容距離は初期値 0.5 タイル。
- 死亡、キャンセル、経路なし、時間切れで歩行状態を停止する。
- 初期版は 1 体につき 1 つの移動操作のみ。新しい移動指示が既存操作を暗黙に上書きすることはない。

## 失敗の返却

`invalid_target`、`path_not_found`、`blocked`、`timeout`、`character_dead`、`cancelled` を区別し、最後の実位置を返す。AI が別の目的地を選べるようにする。

## 受け入れ条件

- 観察者の画面でキャラクターが実際に歩く。壁や水を通過せず、移動時間はゲーム内の速度に従う。
- 到達不能な位置で無限に歩き続けない。
- 停止後に意図しない方向へ歩き続けない。

参照: [歩行状態](https://lua-api.factorio.com/latest/classes/LuaControl.html)、[経路探索](https://lua-api.factorio.com/latest/classes/LuaSurface.html)。
