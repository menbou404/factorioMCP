# 11. 設備とのアイテム移動

## 目的

キャラクターが自分の持ち物を炉や採掘機に入れ、設備の完成品を自分の持ち物へ回収する。これは工場を稼働させるためのゲーム内アイテム移動であり、新しいアイテムを生成する操作ではない。

## 操作

- `get_entity_inventory(target)` は、観察済みで手の届く設備の入力・出力・燃料など、プレイヤーが扱える区画を返す。
- `transfer_item(target, direction, inventory_role, item, count)` は `direction=to_entity` または `from_entity` で、指定区画と AI キャラクターの持ち物の間でアイテムを移す。
- 対象は同じ面に存在する設備の識別子と位置で指定する。初期版は石の炉、燃料式掘削機、箱など、動作を検証した設備と区画に限る。

## 実行規則

1. キャラクターと設備が生存・実在し、距離と勢力の条件を満たすことを確認する。
2. 移動元に指定アイテムがあり、移動先が受け入れ可能であることを確認する。設備の区画とアイテムの適合をゲームのインベントリ API で判定する。
3. 1 回の要求で実際に移った数量を返す。一部しか移らない場合はその数量を明示する。
4. 移動元の減少と移動先の増加が一致することを確認する。失敗時は移動を確定せず、再送で二重移動しない。
5. 人間プレイヤーの持ち物を暗黙に移動元・移動先にしない。

## 受け入れ条件

- 炉へ石炭と鉄鉱石を入れられ、炉でできた鉄板を回収できる。
- 距離外、対象消失、区画違い、容量不足でアイテムが複製・消失しない。
- 操作前後で、移動元と移動先にある対象アイテムの合計が一致する。ただし同じ tick に設備が消費・生産した分はゲームの処理として別に記録する。

参照: [キャラクターと設備のインベントリ](https://lua-api.factorio.com/latest/classes/LuaControl.html)、[インベントリ間の移動と数量](https://lua-api.factorio.com/latest/classes/LuaInventory.html)、[設備のインベントリ](https://lua-api.factorio.com/latest/classes/LuaEntity.html)。
