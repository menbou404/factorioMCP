# 06. 手作業の製作

## 操作

`craft(recipe, count)` は AI キャラクターの手作業製作キューにレシピを追加する。`recipe` は内部名、`count` は正の整数で、1 回の要求に上限を設ける。製作可能なレシピは `list_craftable_recipes` で確認する。

## 実行規則

- 所属勢力でレシピが有効であり、手作業で製作でき、必要な材料が AI キャラクターの持ち物にある場合だけ開始する。
- ゲームの製作 API とキューを用い、材料消費と製作時間をゲーム側に処理させる。完成品を Mod が無償で挿入しない。
- API が返す実際の開始数を返し、要求数がすべて開始できなかった場合は不足理由を示す。
- 完了は製作キューとインベントリの実状態で判定する。研究や材料の変化によって開始できない場合は失敗とする。
- 独立キャラクターで標準製作 API が期待どおり働くかを実機で検証する。成立しないレシピは製作できると表示しない。

## 受け入れ条件

- 材料のないレシピは開始できず、完成品も増えない。
- 研究前のレシピは開始できない。
- 材料消費と完成品の増加が AI キャラクターのゲーム内インベントリに反映される。
- 製作時間を飛ばさない。

参照: [製作可能数と製作キュー](https://lua-api.factorio.com/latest/classes/LuaControl.html)。
