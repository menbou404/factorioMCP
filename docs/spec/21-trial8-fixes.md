# 21. 8 回目の試行で見つかった問題の修正（M13）

## 背景

8 回目の試行（[20-trial7-fixes.md](20-trial7-fixes.md)）で、AI が次の問題を挙げた。

| 区分 | 問題 | 原因 |
| --- | --- | --- |
| Q | 手で鉱石 25 個を掘るのに 50 秒ほどかかり、何度も待った。完了までの見込み時間がほしい | 採掘の進み具合は取得数だけで、残り時間を返していない |
| R | ラボは `input`、組立機は `source` で、組立機に `input` を指定して失敗した | 区画名が設備の種類ごとに違い、別名を受け付けない |
| S | 汲み上げポンプの向きが分かりにくい。水側と出力側を示してほしい | 設置の事前確認と観察で、流体の出口だけを返し、水に向ける側を返していない |

## Q. 採掘の見込み時間

- `mine_entity` の結果と、実行中の採掘の `detail` に `estimated_seconds`（完了までの見込み秒数）を加える。
- 見込みは、対象の採掘時間、キャラクターの採掘速度（勢力と本人の補正を含む）、1 回の採掘で得られる数量、残りの数量、現在の採掘の進み具合から計算する。木のように 1 回で複数個得られる対象も扱う。
- 見込みであり、歩行の中断や対象の消滅で変わることを説明に書く。

## R. 区画名の別名

- 投入側の区画は `input`、取り出し側の区画は `output` を別名として受け付ける。炉と組立機の `input` は `source`、`output` は `result` と同じ区画を指す。ラボの `source` は `input` と同じ区画を指す。
- 結果と `inventory_roles` に表示する区画名は、これまでどおりの名前とする。
- 受け付けない区画名のエラーでは、`valid_roles` と、使える別名を返す。

## S. 汲み上げポンプの水側

- 汲み上げポンプの `check_placement` の結果と観察結果に、水に面する側の向き `water_direction` と、流体の出口の向き `output_direction` を加える。向きは `defines.direction` の値とする。
- `check_placement` で置けない場合の `valid_directions` と `nearby_positions` は、そのまま使える。
- ツールの説明に、汲み上げポンプは `water_direction` の側が水、`output_direction` の側にパイプやボイラーをつなぐことを書く。
