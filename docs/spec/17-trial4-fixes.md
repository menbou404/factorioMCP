# 17. 4 回目の試行で見つかった問題の修正（M9）

## 背景

2026-11-04 の 4 回目の自律試行（[16-trial3-fixes.md](16-trial3-fixes.md)）で、AI が新しい問題を挙げた。この文書は、その原因と修正、または修正しない理由を記録する。修正は区分ごとに PR を分けて入れ、すべて入った後に同じ条件で 5 回目の試行をする。

| 区分 | 問題 | 原因 |
| --- | --- | --- |
| G | (56, 0) への歩行が、理由の分からない `path_not_found` で終わった | 目的地が水のタイルだった。`path_not_found` に目的地の状態を含めていない |
| H | 採掘機がこぼした鉱石が設置の邪魔になったが、`blocking` から直接拾えなかった | `blocking` の要素に `target_ref` が無く、拾うために観察し直す必要があった |
| H | かまどの `result` からの受け渡しが、詳細の無い `missing_materials` で失敗した（2 回） | 取り出し元にそのアイテムが無いとき、何が入っているかを返していない |

## G. 歩行の失敗情報

歩行が `path_not_found` で終わった場合は、`detail` に次を含める。

| 項目 | 内容 |
| --- | --- |
| `goal` | 目的地 |
| `distance` | 現在位置から目的地までの距離 |
| `goal_tiles` | 目的地のタイルがキャラクターと衝突する場合、そのタイル名（例: `["water"]`）。衝突しなければ含めない |
| `goal_entities` | 目的地の周り（キャラクターの大きさ）でキャラクターと衝突するエンティティ（`name`、`type`、`x`、`y`、最大 5 件）。無ければ含めない |
| `nearby_free_position` | 目的地から 10 タイル以内でキャラクターが立てる位置（`LuaSurface.find_non_colliding_position`）。見つからなければ含めない |

`nearby_free_position` は立てる位置であり、そこまでの経路があるとは限らない。キャラクターを動かすのは、AI が改めて `move_to` を呼んだときだけである（テレポートしない規則のため）。

### 試験

- 統合試験に、水のタイルを目的地にした歩行を加える。`path_not_found` の `detail.goal_tiles` に水のタイル名が入り、`nearby_free_position` が返ること。

## H. 阻害物の参照と受け渡しの不足情報

### 阻害物の参照

`check_placement` と `place_entity` の `blocking` の各要素に `target_ref` を含める。観察で付けるものと同じ参照で、同じ期限（60 秒）を持つ。AI は観察し直さずに、`mine_entity` で地面のアイテムを拾ったり、自分の設備を回収したりできる。行動の時点で Mod が対象の実在・距離・所属勢力を検証する規則は変わらない。

### 受け渡しの不足情報

`transfer_item` が取り出し元にそのアイテムが無いために `missing_materials` で失敗した場合は、`detail` に次を含める。

| 項目 | 内容 |
| --- | --- |
| `item` | 指示したアイテム |
| `requested` | 指示した数 |
| `available` | 取り出し元にある数（0） |
| `inventory_role` | 設備の区画名（設備から取り出す場合） |
| `contents` | 取り出し元の区画に入っているアイテム（`name`、`count`、最大 10 件） |

### 試験

- 統合試験に、空の `result` 区画からの受け渡しを加える。`missing_materials` の `detail` に `requested` と `available = 0` と `contents` が入ること。
- 設置の阻害物の `target_ref` で `mine_entity` が始められること。

## 変えないもの

| 指摘 | 扱い |
| --- | --- |
| 最初のツール一覧に Factorio のツールが無かった | Codex 側のツール探索の挙動である。最初の呼び出しから MCP サーバーは応答しており、サーバーの変更は要らない |
| 採掘や製作の完了予想時刻がほしい | 実行中の進捗（`gained`、`remaining`）を M8 で加えた。完了時刻は採掘速度や材料の状況で変わるので、予想値は返さない |
