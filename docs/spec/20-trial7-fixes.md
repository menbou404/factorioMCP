# 20. 7 回目の試行で残った指摘の修正（M12）

## 背景

7 回目の試行（[19-trial6-fixes.md](19-trial6-fixes.md)）で残した指摘のうち、利用者の判断で次の 2 つを修正する。

| 区分 | 問題 | 原因 |
| --- | --- | --- |
| O | 採掘中の設置が `action_conflict` になることが `mine_entity` の説明に無い | 説明は `action_conflict` のヒントにだけ書いた |
| O | 130.6 タイル先への歩行が `out_of_range` になった | `move_to` の説明に 128 タイルの上限が無い |
| O | 必須の引数が欠けたとき、JSON でない文が返った | MCP SDK の入力検証エラーが、そのまま返っている |
| P | 1〜7 回目の試行で、呼び出しの差の大半は水場と鉱石を探す歩行と観察だった | 一度観察した場所の地形と資源を、後から参照する手段が無い |

## O. 説明の追加と入力エラーの形式

- `mine_entity` の説明に、採掘の実行中は設置・受け渡し・回転・レシピの設定が `action_conflict` になることを書く。製作はできる。
- `move_to` の説明に、目的地はキャラクターから直線で 128 タイル以内であること、それより遠い場所へは中継点を置くことを書く。
- 入力検証の失敗（必須の引数の欠落、型の違い、範囲外の値）は、他のエラーと同じ JSON で返す。`error` は `invalid_input`、`detail.errors` は項目ごとの `field`・`type`・`message` の一覧とし、入力の形式を確かめるヒントを付ける。

## P. 探索済みの地図

Mod は、本人の `observe_nearby` で見た範囲の地形と資源を、8×8 タイルの区画ごとに記録する。新しいツール `get_explored_map` で、記録を資源の鉱床、水場、森、岩ごとにまとめて返す。

### 記録

- 観察の円の中に区画全体が入る区画だけを記録する。一部しか見えていない区画は記録しない。
- 区画には、観察した時刻、資源の種類ごとのタイル数・総量・代表位置、水タイルの数と岸の代表位置、木と岩の数を持つ。
- 同じ区画を再び観察したら、記録を上書きする。掘り尽くした資源や、消えた水場は記録から消える。
- 観察の絞り込み（`types`・`names`・`owned_only`・`include_resources`・`include_tiles`）は記録に影響しない。
- 面ごとに最大 16384 区画とし、超えたら最も古い区画から消す。
- 管理用のリセットで消す。

### 情報の制限

[03-observation.md](03-observation.md) の範囲を守る。

- 記録するのは、本人の観察で見た区画だけである。勢力のチャート、未観察の地形、地図生成の情報は使わない。
- 値は観察した時点のものであり、`observed_tick` を付けて返す。観察の後の変化は、同じ区画を再び観察するまで反映しない。

### `get_explored_map` の結果

- キャラクターの位置、区画の大きさ、記録した区画の数と範囲を返す。
- `resources`：資源の種類ごとに、隣り合う区画をつないだ鉱床を返す。タイル数、総量、範囲、キャラクターに最も近い代表位置とその距離、最も古い観察時刻を持つ。
- `water`：水タイルのある区画をつないだ水場を返す。タイル数、範囲、キャラクターに最も近い岸の位置とその距離を持つ。岸は、上下左右に水でないタイルが接する水タイルである。
- `trees`・`rocks`：木・岩のある区画をつないだまとまりを返す。数、範囲、最も近い代表位置とその距離を持つ。
- 各一覧はキャラクターに近い順に並べ、`limit`（1〜50、既定 10）件までとする。省いた件数も返す。`resource_names` で資源の種類を絞り込める。

## 効果の確認（2026-11-04）

O・P の修正後、7 回目と同じ条件（シード 123、平和モード、同じ指示文、`gpt-6.1-sol`）で 8 回目の試行をした。利用者が画面付きの Factorio からサーバーに接続し、観戦モードで AI の動きを見た。8 回目も目標を達成し、組立機が作った赤サイエンス 10 個で `gun-turret` を研究した。

| 項目 | 7 回目（M12 前） | 8 回目（M12 後） |
| --- | --- | --- |
| ツール呼び出し | 300 回 | 288 回 |
| ツールのエラー | 12 回 | 9 回 |
| 入力トークン | 約 531 万 | 約 535 万 |
| 所要時間 | 16 分 | 16 分 |

AI は `get_explored_map` を一度も呼ばなかった。指示文が「歩いて観察し直して探索する」と案内しているためと考えられる。地図の効果は、指示文で地図に触れた次の試行で確かめる。8 回目の指摘と、その扱いは [21-trial8-fixes.md](21-trial8-fixes.md) に記録する。
