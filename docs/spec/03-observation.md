# 03. 観察と情報制限

## 観察できる情報

| 情報 | 初期版の範囲 |
| --- | --- |
| 周囲 | キャラクターを中心とする半径 16 タイル。通行できない地形タイル、資源、設備、敵、落ちているアイテムのうちゲーム内に存在するもの |
| 本人 | 位置、体力、現在の操作状態、主インベントリの内容 |
| 近くの設備 | 観察範囲内で手の届く設備の状態と、通常のプレイヤーが確認できる入出力・燃料の数量 |
| 製作 | 現在の技術で有効な手作業レシピ、材料・生成物、現在の持ち物で製作できる数量 |
| 研究 | 所属勢力が研究済みの技術と現在進行中の研究 |

観察は呼び出し時点のスナップショットとゲームの tick を返す。AI クライアントが過去の観察を記憶することは認めるが、MCP は未観察の場所の地形や設備を先読みして提供しない。研究とレシピは勢力で共有されるゲーム内知識として扱う。

## 制約

- 周囲の観察範囲を API 引数で無制限に広げられない。半径は初期版では固定する。
- 大量のエンティティがある場合は件数上限と続き位置を返し、情報を黙って欠落させない。
- 内部 API が取得できても、敵の未観察位置、マップ全体の資源分布、他勢力の研究状態は返さない。
- 人間プレイヤーの持ち物を AI 自身の持ち物として返さない。
- 設備の中身を見る操作は、AI キャラクターが同じ面で対象に手が届く場合に限る。
- 観察は読み取りのみとし、チャートの強制公開や地形生成を副作用として行わない。

## 返却形式

機械処理できる JSON を返す。位置には面と `x`,`y`、アイテムには内部名と数量を含める。表示名への翻訳は AI クライアントの表示層に任せる。結果が多い場合でも 1 回の RCON 応答が過大にならないよう、上限とページングを設ける。

## 受け入れ条件

- 半径外の設備は、ゲーム内に存在しても結果に含まれない。
- 採掘の前後で観察した資源量と本人の持ち物の変化を確認できる。
- 研究状況と製作可能数は、その tick のゲーム状態に一致する。

参照: [周囲のエンティティ検索](https://lua-api.factorio.com/latest/classes/LuaSurface.html)、[インベントリと製作可能数](https://lua-api.factorio.com/latest/classes/LuaControl.html)、[勢力の研究情報](https://lua-api.factorio.com/latest/classes/LuaForce.html)。
